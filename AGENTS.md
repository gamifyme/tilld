# Agent Instructions

These repository-level instructions apply to coding agents working in this repo, including Codex-style agents.

## Commits

- Use Conventional Commits for commit messages, for example `feat: add auth routes` or `chore: update docker config`.
- Do not add agent/tool attribution trailers such as `Co-authored-by` unless the user explicitly asks for them.

## Scope

- Treat these instructions as persistent repo policy for future sessions.
